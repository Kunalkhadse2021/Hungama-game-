🎮 Hangman Game Using Python

📌 Project Description

Hangman is a word guessing game developed using Python. The player must guess the hidden word by entering one letter at a time.

🚀 Features

Random word selection

Five predefined words

Maximum 6 incorrect attempts

Letter-by-letter guessing

Win and Game Over messages

Simple console-based interface

🛠️ Technologies Used

Python 3

Random Module

▶️ How to Run the Project

Install Python 3.

Download or clone this repository.

Open the project folder in VS Code or Command Prompt.

Run this command:

python hangman_game.py

🎯 Game Rules

Guess one letter at a time.

Each wrong guess reduces one attempt.

You have a maximum of 6 incorrect attempts.

Guess the complete word to win the game.
